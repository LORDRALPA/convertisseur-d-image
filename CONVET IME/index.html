Architecture

Un moteur
multi-stratégies.

Pour chaque type de source, le moteur essaie plusieurs approches en cascade pour maximiser les chances de conversion.

Source

🖼️ Images raster

  • Pillow.open() + détection du mode
  • Conversion de mode (RGBA, P, L…)
  • Sauvegarde dans le format cible
Source

🎭 PSD Photoshop

  • Pillow (mode PSD) → PNG intermédiaire
  • Fallback ImageMagick si Pillow échoue
  • Conversion vers le format cible
Source

📄 PDF / AI

  • PyMuPDF fitz.open() + pixmap 2× (HiDPI)
  • PNG temporaire en mémoire
  • Fallback ImageMagick -density 150
Source

✏️ SVG

  • Extraction PNG base64 embarqué dans le SVG
  • Fallback cairosvg (si GTK disponible)
  • Fallback ImageMagick
Cible

✏️ Vers SVG

  • Conversion vers PNG intermédiaire
  • Encodage base64 du PNG
  • Génération du wrapper SVG XML
Cible

🎭 Vers PSD

  • Conversion Pillow vers PNG intermédiaire
  • ImageMagick convert → .psd
  • Vérification de la taille de sortie
